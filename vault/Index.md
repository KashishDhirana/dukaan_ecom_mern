# Dukaan
---
[**Dukaan**](https://github.com/KashishDhirana/dukaan_ecom_mern) is an e-commerce website which is build using [**React.js**](https://react.dev). And supporting libraries like:
- [**Tanstack Router**](https://tanstack.com/router/latest) (Routing Management)
- [**Tanstack Start**](https://tanstack.com/start/latest) (SSR and Server capabilities)
- [**Tanstack Query**](https://tanstack.com/query/latest) (Query state management)
- [**Tanstack Form**](https://tanstack.com/form/latest) (Form state management)
- [**Tanstack Store**](https://tanstack.com/store/latest) (React state management)
- [**Vite**](https://vite.dev/) (Build Tool)
- [**Shadcn**](https://ui.shadcn.com/) (UI Component library)
- [**Tailwindcss**](https://tailwindcss.com/) (CSS framework)
- [**Zod**](https://zod.dev/) (Schema Validation Lib)
and many other in `package.json`
